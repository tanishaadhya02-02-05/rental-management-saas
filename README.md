# Rental Management SaaS

A serverless multi-tenant rental management system built as an AWS learning project.

## Architecture

- Node.js
- AWS Cognito
- API Gateway
- AWS Lambda
- DynamoDB
- Amazon S3
- Amazon SES
- CloudWatch

## Core Features

- Owner authentication
- Multi-tenant data isolation
- Property and room management
- Rental application generation
- Unique tenant application links
- Tenant information collection
- KYC document storage
- PDF generation
- Email notifications
- Rental renewal and history
